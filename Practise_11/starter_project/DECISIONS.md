# Ключевые решения по проекту (Практическая работа №11)

1. **Построчное чтение через `Files.newBufferedReader` в `try-with-resources` и разделение ошибок:**
   Файл читается построчно с помощью `BufferedReader`, что не загружает весь файл целиком в память. Ошибки открытия или чтения самого файла (`IOException`) не перехватываются внутри `importFile` и сразу прерывают операцию, тогда как обработка каждой отдельной строки обёрнута в метод `processSingleLine` с локальным `try-catch`, поэтому сбой одной записи фиксируется в `ImportResult` с номером строки и не останавливает дальнейший импорт.

2. **Локализация правила обязательного поля и лимита длины (Вариант 4) в `ClientValidator`:**
   Проверка обязательности поля `name` и его максимальной длины (`MAX_NAME_LENGTH = 25`) сосредоточена исключительно в методе `validateName` класса `ClientValidator`. Ни парсер `ClientCsvParser`, ни координатор `ClientImporter` не дублируют правила валидации полей, поэтому изменение порога длины или добавление новых проверок выполняется только в одном классе.
